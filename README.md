# Инструкции за подкарване

## Изисквания

* NodeJs v20.XX.X+

* npm v10.X.X+

* PostgreSQL

## Стъпки

* В руут директорията на проекта използвате командата '''npm install'''

* Създавате база данни в постгре и попълванте нужните полета в .env файла

'''
  JWT_SECRET=<Таен ключ>
  DB_PORT=<Порта на базата данни>
  API_PORT=<Порта, на който ви е сървъра (3000 е окей)>
  DATABASE_URL=<URL-а на базата данни - взима се от Постгре>
  NODE_ENV=<DEV>
'''

* В руут директорията изпълнявате командата '''npm start'''

## Ако всичко е спазено ще имате АПИ на порт 3000 и работеща потребителска част на порт 4200
